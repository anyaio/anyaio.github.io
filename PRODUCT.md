# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Jekyll 4 single page (`_layouts/default.html`) built by GitHub Actions, served by GitHub Pages at anya.io. Styling: Tailwind from the CDN, no compilation step (user's choice). Works come from `_data/works.yml`.

## Users

Anya Belova, game / 3D environment artist. Visitors: studios, recruiters and art leads looking at her environment work (level blockouts, renders). Anya edits the site herself from Windows in the github.com browser editor.

## Product Purpose

Show Anya's current environment art so a studio decides to contact her. Success: a visitor sees strong current work in the first viewport and finds her Instagram.

## Operating Context

Anya adds a picture by uploading an image to `img/portfolio/` and adding two lines to a project in `_data/works.yml` in the browser. Any design must keep that workflow: no build tools on her side, no per-work HTML.

## Capabilities and Constraints

- Projects list: title, img (main image), date, category, description, optional slides (each with img and description), optional link to a playable game in `games/`. Shown in file order.
- 3D Models: `_data/models.yml` (title, img), small images at the bottom of the page, no dates.
- Eco Room and the 2015 "Early work" archive were removed from the site on Anya's request (2026-11-05); they remain in git history.
- Contact: Instagram https://www.instagram.com/anyabeloved_/ only. Old links (twitter anya_io, instagram anya_phuket, github anyaio) and the 2015 story timeline are retired.
- Images are JPGs up to 1920px wide; no thumbnails.

## Brand Commitments

Name: Anya Belova. Domain anya.io. The 2015 voice ("let me design for you", "my dad made me this website") is retired: she is an adult professional now.

## Evidence on Hand

- Current work: `img/portfolio/aquarium-*.jpg` (Aquarium Level, Sep 2026) and `doomsday-*.jpg` (Doomsday Level Blockout, Aug 2026), Level Design; `mr-stickbug-1.jpg` and `games/mr-stickbug.html` (mr.stickbug, 2D Platformer, Oct 2026).
- No current portrait (the 2015 one was removed). No CV, clients or studio credits on hand: do not invent them.

## Product Principles

1. The work leads; the interface recedes.
2. Adding a work stays a 2-step browser edit.
3. Only current work; no filler.

Visual direction: the user chose the category standard (a clean dark portfolio, ArtStation-level craft) over concept directions on 2026-10-03.
